Configuração para GitHub → web2app

  1. Salve esta página como index.html
  2. Crie um repositório no GitHub e envie o arquivo
  3. Ative Settings → Pages → Deploy from a branch (branch main / root)
  4. Acesse a URL do GitHub Pages no celular e toque em Adicionar à Tela de Início
  5. Para gerar APK: use PWABuilder ou web2apk apontando para sua URL
